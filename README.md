# Banking Customer Analytics

An interactive Banking Customer Analytics dashboard built using Tableau to analyze customer behavior, balances, credit scores, activity, and customer segments.

## Project Overview

This project analyzes banking customer data and presents key insights through interactive Tableau visualizations.

## Tools & Technologies

- Tableau
- CSV Dataset
- Data Visualization
- Data Analysis

## Dashboard Analysis

The project includes analysis of:

- Total Customers
- Total Balance
- Average Balance
- Active Customers
- Customers by Gender
- Customers by Age Group
- Customers by Geography
- Customers by Customer Segment
- Customers by Credit Score

## Key Insights

- Customer distribution is analyzed across different age groups.
- Customer activity is compared between active and inactive customers.
- Customer distribution is analyzed across France, Germany, and Spain.
- Customer segments are compared based on customer count.
- Credit score distribution is visualized using score ranges.

## Dataset

The analysis uses a banking customer dataset containing customer demographics, account information, credit scores, balances, and activity status.
